# 🪙 CoinFlux: Live Fiat & Crypto Converter

A mobile-first, real-time currency converter that seamlessly bridges traditional fiat money (USD, IDR, EUR) and cryptocurrencies (BTC, ETH, SOL).

## Features
- **Real-Time Data:** Live exchange rates powered by Coinbase API.
- **Unified Interface:** Convert between Fiat and Crypto in a single, unified list.
- **Personalized Watchlist:** Add, remove, and save your favorite currencies to your browser's local storage.
- **Smart Formatting:** Accurately handles massive numbers (like IDR) and micro-decimals (like crypto tokens).
- **Mobile-First Design:** Crafted with Tailwind CSS for a beautiful, responsive, app-like experience.

## Getting Started
Simply run a local web server in this directory:
```bash
python3 -m http.server 8333
```
Then open your browser to `http://localhost:8333` (or your server's IP).
